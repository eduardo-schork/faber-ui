# Faber UI logo kit

The mark is a hexagonal geode: an obsidian rind, a pale band, and an amethyst heart cut in two
steps. The wordmark is "Faber UI" in Plus Jakarta Sans Bold, outlined, so no file here needs a font.

## Files

| File                           | Use                                                       |
| ------------------------------ | --------------------------------------------------------- |
| `faber-ui-horizontal.svg`      | Mark and wordmark, for light backgrounds. The default.    |
| `faber-ui-horizontal-dark.svg` | Mark and wordmark, for dark backgrounds.                  |
| `faber-ui-mark.svg`            | The mark alone, for light backgrounds.                    |
| `faber-ui-mark-dark.svg`       | The mark alone, for dark backgrounds.                     |
| `faber-ui-icon.svg`            | The mark on an obsidian plate with rounded corners.       |
| `faber-ui-mark-512.png`        | The mark at 512 pixels, where SVG is not accepted.        |
| `faber-ui-icon-512.png`        | The icon at 512 pixels, for avatars and package listings. |

SVG is the source of truth. Export other sizes from it when needed.

## Rules

- Use the `-dark` file on dark backgrounds: its rind is lighter so the hexagon does not disappear.
- Use the mark alone where the name is already next to it or the space is 32 pixels or less.
- Keep clear space around the logo equal to one quarter of the height of the mark.
- Do not show the mark below 16 pixels or the horizontal lockup below 20 pixels high.
- Do not recolour, rotate, stretch, outline, or add effects to the logo, and do not rearrange the
  mark and the wordmark.
