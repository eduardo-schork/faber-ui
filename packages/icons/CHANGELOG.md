# @faber-ui/icons

## 0.2.0

### Minor Changes

- 15cec19: Widen the icon set from 10 to 70 outline icons, drawn on the same 16 by 16 grid with a 1.5 stroke.

  - Arrows and chevrons: `ArrowUpIcon`, `ArrowDownIcon`, `ArrowLeftIcon`, `ChevronUpIcon`,
    `ChevronDownIcon`, `ChevronLeftIcon`, `ChevronRightIcon`, `ChevronsLeftIcon`, `ChevronsRightIcon`,
    `ChevronsUpDownIcon`.
  - Actions: `MinusIcon`, `SearchIcon`, `FilterIcon`, `SortIcon`, `EditIcon`, `DownloadIcon`,
    `UploadIcon`, `ShareIcon`, `RefreshIcon`, `LinkIcon`, `ExternalLinkIcon`.
  - Navigation: `MenuIcon`, `MoreHorizontalIcon`, `MoreVerticalIcon`, `HomeIcon`, `GridIcon`,
    `ListIcon`, `SettingsIcon`, `SlidersIcon`, `LogInIcon`, `LogOutIcon`.
  - Status: `InfoIcon`, `HelpCircleIcon`, `AlertCircleIcon`, `AlertTriangleIcon`, `CheckCircleIcon`,
    `CloseCircleIcon`.
  - People and messages: `UserIcon`, `UsersIcon`, `BellIcon`, `MailIcon`, `MessageIcon`.
  - Objects: `CalendarIcon`, `ClockIcon`, `FileIcon`, `FileTextIcon`, `FolderIcon`, `ImageIcon`,
    `BookmarkIcon`, `StarIcon`, `HeartIcon`, `MapPinIcon`, `GlobeIcon`, `CodeIcon`.
  - Security and media: `LockIcon`, `UnlockIcon`, `EyeIcon`, `EyeOffIcon`, `PlayIcon`, `PauseIcon`.

## 0.1.0

### Minor Changes

- First public release of Faber UI: design tokens as typed constants and CSS variables, light and
  dark themes, the bundled Plus Jakarta Sans font, an initial icon set, and the React component
  library with composable parts.
