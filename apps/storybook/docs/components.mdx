# Component guides

These guides explain the intent and stable behavior of each implemented React component. They are
written for people and for tools that need explicit context. Stories remain the place to inspect
visual states and interact with controls; exported TypeScript types remain the source of truth for
the exact prop surface.

- [Button](?path=/docs/components-button--docs): text or icon-and-text action.
- [Checkbox](?path=/docs/components-checkbox--docs): independent binary selection.
- [IconButton](?path=/docs/components-iconbutton--docs): icon-only action.
- [LinkButton](?path=/docs/components-linkbutton--docs): navigation with the weight of a button.
- [Link](?path=/docs/components-link--docs): navigation link, with router support.
- [Input](?path=/docs/components-input--docs): single-line text-like input.
- [Radio](?path=/docs/components-radio--docs): one option in a named exclusive set.
- [RadioGroup](?path=/docs/components-radiogroup--docs): fieldset, legend, and messages for a set
  of radios.
- [Switch](?path=/docs/components-switch--docs): immediately applied on/off setting.
- [Select](?path=/docs/components-select--docs): native single-value option list.
- [SegmentedControl](?path=/docs/components-segmentedcontrol--docs): one of a few visible options.
- [Textarea](?path=/docs/components-textarea--docs): multiline text input.
- [Field](?path=/docs/components-field--docs): label, description, and error composition.
- [Flex](?path=/docs/components-flex--docs): responsive flex layout, including HFlex and VFlex.
- [Container](?path=/docs/components-container--docs): responsive page width.
- [CenterFlex](?path=/docs/components-centerflex--docs): centered flex composition.
- [Text](?path=/docs/components-text--docs): semantic body text and inline text.
- [Title](?path=/docs/components-title--docs): semantic heading levels.
- [Divider](?path=/docs/components-divider--docs): horizontal or vertical separator.
- [AlertDialog](?path=/docs/components-alertdialog--docs): modal confirmation with two actions.
- [Box](?path=/docs/components-box--docs): block container with token padding.
- [Grid](?path=/docs/components-grid--docs): responsive columns and tracks.
- [List](?path=/docs/components-list--docs): unordered and ordered lists.
- [DescriptionList](?path=/docs/components-descriptionlist--docs): name and value pairs.
- [CodeBlock](?path=/docs/components-codeblock--docs): source code with a copy button.
- [SkipLink](?path=/docs/components-skiplink--docs): keyboard jump past the navigation.
- [NavLink](?path=/docs/components-navlink--docs): destination with a current-page state.
- [Header](?path=/docs/components-header--docs): application top bar.
- [Footer](?path=/docs/components-footer--docs): closing region of a page.
- [SideNav](?path=/docs/components-sidenav--docs): grouped vertical navigation.
- [Card](?path=/docs/components-card--docs): bordered surface for related content.
- [Table](?path=/docs/components-table--docs): styled native table.
- [Alert](?path=/docs/components-alert--docs): message that stands out from its surroundings.
- [Badge](?path=/docs/components-badge--docs): short, read-only metadata.
- [Avatar](?path=/docs/components-avatar--docs): identity image with a fallback.
- [Spinner](?path=/docs/components-spinner--docs): indeterminate wait indicator.
- [Skeleton](?path=/docs/components-skeleton--docs): placeholder shape for loading content.
- [VisuallyHidden](?path=/docs/components-visuallyhidden--docs): content for assistive technology
  only.
- [Autocomplete](?path=/docs/components-autocomplete--docs): text input with native suggestions.
- [Slider](?path=/docs/components-slider--docs): native range input.
- [Tabs](?path=/docs/components-tabs--docs): switch between related views in place.
- [Accordion](?path=/docs/components-accordion--docs): native disclosure sections.
- [Breadcrumb](?path=/docs/components-breadcrumb--docs): trail to the current page.
- [Pagination](?path=/docs/components-pagination--docs): move between pages of a list.
- [Progress](?path=/docs/components-progress--docs): measurable progress.
- [Toast](?path=/docs/components-toast--docs): brief notification after an action.
- [Tooltip](?path=/docs/components-tooltip--docs): short hint about a control.
- [Popover](?path=/docs/components-popover--docs): panel anchored to a button.
- [Menu](?path=/docs/components-menu--docs): list of actions behind a button.
- [Dialog](?path=/docs/components-dialog--docs): modal task or decision.
- [Drawer](?path=/docs/components-drawer--docs): modal panel docked to an edge.

Each guide follows the same order: purpose, when to use, contract, accessibility, customization,
example, and boundaries. The descriptions cover only implemented behavior; future ideas are called
out as such.
