# RadioGroup

[Interactive stories and prop reference](?path=/docs/molecules-radiogroup--docs)

## Purpose and when to use it

Use `RadioGroup` to give one related set of `Radio` options a visible group label, description,
and validation message. Each option must share the same native `name`.

## Behavioral contract

- Renders a native `fieldset` and `legend`; the fieldset receives the forwarded ref.
- Does not own selection state or clone its children. Each `Radio` preserves its native value,
  registration props, and events.
- Optional description and error content are connected to the group with stable IDs.
- An error makes the group invalid by default; `invalid` can override that decision.
- Native fieldset props, `className`, and `style` remain available.

## Accessibility

The fieldset and legend give screen-reader users the same context visible users receive. Keep each
radio label unique and use one shared name for exclusive selection.

## Customization

Spacing, typography, and semantic error colors use design tokens. The group can be wrapped by
styled-components without changing the radio inputs.

## Example

```tsx
import { Radio, RadioGroup } from '@faber-ui/react';

<RadioGroup label="Material" error={errors.material?.message}>
  <Radio label="Amethyst" value="amethyst" {...register('material')} />
  <Radio label="Obsidian" value="obsidian" {...register('material')} />
</RadioGroup>;
```

## Composition

`RadioGroupRoot` is the `fieldset`, `RadioGroupLabel` its `legend`, `RadioGroupOptions` the stack
of radios, and `RadioGroupMessage` and `RadioGroupError` the two text lines. `RadioGroup` connects
the description and error to the fieldset; in a composition set `aria-describedby` yourself.

```tsx
import { RadioGroupLabel, RadioGroupOptions, RadioGroupRoot } from '@faber-ui/react/radio-group';

<RadioGroupRoot>
  <RadioGroupLabel>Plan</RadioGroupLabel>
  <RadioGroupOptions>
    <Radio label="Starter" name="plan" value="starter" />
    <Radio label="Team" name="plan" value="team" />
  </RadioGroupOptions>
</RadioGroupRoot>;
```

## Boundaries

Validation, translation, selected value, and form state belong to the application. `RadioGroup`
provides structure and messages rather than a custom selection state manager.
