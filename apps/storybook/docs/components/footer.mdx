# Footer

<Primary />

<Controls />

## Purpose and when to use it

Use `Footer` for the closing region of a page: links, legal text, and credits.

## Behavioral contract

- Renders a `footer` and forwards native props and its ref.
- Sets a top border, block padding, secondary text color, and a smaller font size from tokens.

## Accessibility

At the top level of the page a `footer` is the content information landmark.

## Customization

Target `faber-ui-footer`. Lay the columns out with `Grid`.

## Example

```tsx
import { Footer } from '@faber-ui/react/footer';

<Footer>
  <Grid columns={{ MOBILE: 1, TABLET: 3 }} gap="XL">
    <About />
    <Links />
    <Legal />
  </Grid>
</Footer>;
```

## Boundaries

The footer has no columns or link groups of its own.
