# SegmentedControl

<Primary />

<Controls />

## Purpose and when to use it

Use `SegmentedControl` to choose one of a few short, mutually exclusive options that are all
visible at once, such as a view mode or a size. Use `RadioGroup` when options need descriptions,
and `Select` when there are more than about five.

## Behavioral contract

- `SegmentedControl` renders a native `fieldset` with a `legend` and forwards the fieldset ref.
- Each `Segment` renders a native radio input inside a label and forwards the input ref.
- Segments require `name` and `value`. Segments that share a name are exclusive, and keep native
  `checked`, `defaultChecked`, `onChange`, `disabled`, and form-library registration props.
- The control does not own the selected value or clone its children.
- `labelHidden` keeps the legend for assistive technology without displaying it.
- `size` accepts values from `SEGMENTED_CONTROL_SIZES` and defaults to `medium`.

## Accessibility

Because the segments are native radios, the group is announced with its legend, arrow keys move
the selection, and Tab enters and leaves the group once. Always provide a `label`, even when it is
hidden.

## Customization

Track, selected, focus, and disabled states consume semantic and dimensional tokens. `className`
and `style` on a `Segment` apply to its label wrapper; other props reach the input.

## Example

```tsx
import { Segment, SegmentedControl } from '@faber-ui/react/segmented-control';

<SegmentedControl label="Density">
  <Segment name="density" value="comfortable" defaultChecked>
    Comfortable
  </Segment>
  <Segment name="density" value="compact">
    Compact
  </Segment>
</SegmentedControl>;
```

## Boundaries

This is a single-selection form control, not a tab list or a toolbar of toggle buttons. It does
not show descriptions or validation messages.
