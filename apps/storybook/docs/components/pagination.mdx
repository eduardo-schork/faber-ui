# Pagination

[Interactive stories and prop reference](?path=/docs/molecules-pagination--docs)

## Purpose and when to use it

Use `Pagination` to move between pages of a long list or table.

## Behavioral contract

- Renders a `nav` landmark with a list of native buttons and forwards the `nav` ref.
- Controlled only: `page` is the current page starting at 1, `count` is the number of pages, and
  `onPageChange` receives the requested page.
- Always shows the first and last page and `siblingCount` pages around the current one (default 1),
  collapsing longer gaps into an ellipsis.
- Previous and next are disabled on the first and last page.
- Every piece of built-in copy is replaceable: `aria-label`, `previousLabel`, `nextLabel`, and
  `getPageLabel`.

## Accessibility

The current page carries `aria-current="page"` and each button has a full name such as "Page 4".
Ellipses are hidden from assistive technology.

## Customization

Buttons use semantic colors and dimensional tokens; the selected page uses the primary role.

## Example

```tsx
import { Pagination } from '@faber-ui/react/pagination';

<Pagination count={pageCount} page={page} onPageChange={setPage} />;
```

## Composition

`PaginationRoot` is the `nav`, `PaginationList` the list, `PaginationButton` one control, and
`PaginationEllipsis` the gap marker. `PaginationButton` takes `current` and every `Button` prop.
`getPaginationRange(count, page, siblingCount)` returns the same page list `Pagination` renders,
with `PAGINATION_ELLIPSIS` where pages are skipped.

```tsx
import { PaginationButton, PaginationList, PaginationRoot } from '@faber-ui/react/pagination';

<PaginationRoot aria-label="Results">
  <PaginationList>
    <li>
      <PaginationButton onClick={loadPrevious}>Newer</PaginationButton>
    </li>
    <li>
      <PaginationButton onClick={loadNext}>Older</PaginationButton>
    </li>
  </PaginationList>
</PaginationRoot>;
```

## Boundaries

`Pagination` does not fetch or slice data, render links, or offer a page-size selector.
