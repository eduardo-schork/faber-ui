# Accordion

<Primary />

<Controls />

## Purpose and when to use it

Use `Accordion` to let readers reveal sections of secondary content one at a time, such as
frequently asked questions.

## Behavioral contract

- `Accordion` renders a `div` that groups the items and forwards its ref.
- `AccordionItem` renders a native `details` element with its `summary` and forwards the `details`
  ref. `summary` is the always-visible heading.
- Open state is native: use `open`, and listen with `onToggle`.
- Items that share a native `name` are exclusive; opening one closes the others.

## Accessibility

The native disclosure is keyboard operable, announces its expanded state, and its hidden content
is found by the browser's find-in-page.

## Customization

Borders, spacing, and typography use tokens. The indicator rotation respects reduced motion.

The content of an item rises into place when the item opens.

## Example

```tsx
import { Accordion, AccordionItem } from '@faber-ui/react/accordion';

<Accordion>
  <AccordionItem summary="How long does shipping take?" name="faq" open>
    Orders ship within two business days.
  </AccordionItem>
  <AccordionItem summary="Can I return an item?" name="faq">
    Returns are accepted for thirty days.
  </AccordionItem>
</Accordion>;
```

## Composition

`AccordionItem` takes the summary as a prop. When the summary row needs its own structure, use
`AccordionItemRoot` (the native `details`), `AccordionSummary`, and `AccordionContent` directly.
`AccordionItemRoot` accepts the same native props, including `open` and `name`.

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItemRoot,
  AccordionSummary,
} from '@faber-ui/react/accordion';

<Accordion>
  <AccordionItemRoot name="faq">
    <AccordionSummary>
      <HFlex align="center" gap="XS">
        Shipping <Badge>2 days</Badge>
      </HFlex>
    </AccordionSummary>
    <AccordionContent>Orders ship within two business days.</AccordionContent>
  </AccordionItemRoot>
</Accordion>;
```

## Boundaries

The open and close change is not animated, and the summary is not wrapped in a heading element;
pass a heading in `summary` when the document outline needs one.
